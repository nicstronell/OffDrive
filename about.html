off Drive Music - about

So this music player has 3 main objectives:
  1. Be able to play music straight off a Google Drive (anywhere via a browser)
  2. Not require a backend server (pure html/javascript)
  3. Allow me not have to choose what music to listen to
This has resulted in some functionality restrictions which means this might not be the music solution for you


Briefly, the system operates by
  • the user logging in with their Google account via the button
  • The app then scans that google drive for a directories called "Music" and asks the user which one contains the files they want to listen to via the app 1
  • The files are then indexed (using the directory information) and a random selection of 16 songs is added to the playlist and they begin to play
  • After that playlist is finished, another random 16 is chosen (which have not been previously played).
That was basically all I wanted, but there is a bit more, with quirks because of the technical aim. You may also notice a set of files call "OffDrive.*" appearing on your Google Drive. Longish story, but you really only need the OffDrive.index file - this is the index of your music. I will probably change this soon not to save all the backups.

The initial indexing uses the file system to provide the song/artist/album info, which is why it's best to set up the directories in the expected manner. Obviously, the music files have that information in them, but opening each song to get that info would be time and network intensive, so, instead, as the files play, the song title is updated from the tags in the file. The artist and album are not automatically updated, but you can choose to use the info in the file, or the directory tree, by (when using desktop, not mobile) hover over the song/album/artist and you'll see a couple of icons to update from the file tags or the directory tree. If none of that is accurate, you can click and manually edit song/album/artist.

Sadly, a major failing of this app is the Google authentication which runs out every 60 minutes. So every 60 minutes, there will be a prompt to login to Google again. The player will also stop playing at this time because, it can't load th next song, nor update the index with the "played" count.

Well (on desktop, not mobile) when a song is playing and you hover over the song name, you will see a "hamburger" drag icon to the left of the name. Drag the playing song over the icon to drop it into the "best songs ever play list".

Depending on how many files you've got, this will take a while, but you can carry on playing songs normally as the re-indexing happens.
